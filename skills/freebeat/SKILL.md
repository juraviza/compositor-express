# Freebeat

Use this skill when the user wants to create a music video with Freebeat and needs expert guidance instead of generic prompt advice.

## Quick workflow

1. Ask for the minimum useful inputs:
   - MP3 or song link
   - lyrics
   - target platform (TikTok/Reels, YouTube, both)
   - desired vibe, artist reference, or visual reference if available
2. Identify the strongest test segment first. Prefer 15 to 30 seconds, usually the hook, chorus, or drop.
3. Choose the right Freebeat mode before prompting:
   - Singing MV for performer, avatar, or lip-sync feel
   - Storytelling MV for narrative scenes
   - Abstract MV for mood-first visuals
   - Lyrics video when text legibility is a priority
4. Split the song into sections before attempting a full video.
5. Write prompts per section, not one vague prompt for the whole song.
6. Generate a short proof first, then refine, then scale.
7. Regenerate only weak scenes instead of restarting everything.

## Decision rules

### A. User wants the most professional result
Do not start with the full song. Start with the most commercially important 15 to 30 seconds and validate:
- visual style
- character consistency
- lyric readability
- beat sync

### B. User wants a full music video fast
Still divide the song into blocks:
- intro
- verse
- pre
- chorus
- bridge
- outro

Then define a visual role for each block.

### C. User wants a singer or recurring character
Prefer 1 or 2 prepared characters max. Keep wardrobe, age, lighting, and style stable across prompts.

### D. User wants a lyric video
Prioritize:
- readable typography
- clean contrast
- restrained background complexity
- correct timing over flashy visuals

## Prompt pattern

Build prompts from these parts:
- subject
- setting
- mood
- camera language
- lighting/color
- style reference
- motion behavior
- constraints

Template:

`[subject] in [setting], [mood], [lighting/color], [camera language], [style reference], synced to rising musical energy, clean cinematic motion, consistent character design, no distorted face, no extra people, no random costume changes`

## Recommended delivery pattern

When the user gives you a song, respond in this order:
1. best mode in Freebeat
2. best first test segment
3. section-by-section visual plan
4. exact prompt for the first render
5. what to review after the first output

## Credit and quality rules

- Treat full-song renders as expensive.
- Spend credits validating the hook first.
- Regenerate only bad scenes.
- If the result is close but not premium, keep Freebeat for generation and recommend a light finishing pass outside it only if needed.

## Common mistakes to prevent

- generating the full song too early
- using vague prompts
- mixing too many aesthetics in one pass
- adding too many characters
- ignoring lyric legibility
- judging the tool from the first render only
