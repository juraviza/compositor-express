# APP MOZART WEB - Próximos pasos ejecutables

## Objetivo inmediato
Pasar de concepto + mockups a una base implementable.

## Prioridad 1
Construir primero estas 2 pantallas:
1. Home
2. Estudio creativo

## Home debe incluir
- hero potente
- CTA principal
- tarjetas de estilos
- accesos rápidos
- preview de proyectos recientes

## Estudio creativo debe incluir
- panel izquierdo de producción
- editor central grande
- panel derecho Asistente Mozart
- acciones rápidas de mejora
- guardado y exportación visibles

## Sistema visual inicial
- fondo oscuro premium
- paneles antracita
- acentos magenta / azul eléctrico
- tipografía limpia y moderna
- sombras suaves y brillo sutil

## Componentes mínimos
- Button
- Card
- StyleChip
- EmotionChip
- Sidebar
- Topbar
- LyricsEditor
- AssistantActionList
- ProjectCard

## Estructura técnica inicial
- app/
- components/
- lib/
- styles/
- public/

## Orden de ejecución recomendado
1. montar layout global
2. montar home
3. montar estudio creativo
4. pulir sistema visual
5. conectar acciones fake/mock
6. conectar backend después

## Criterio de éxito
Que mañana ya exista una base visible y convincente para APP MOZART WEB, no solo documentos.
